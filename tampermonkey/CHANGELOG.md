# Changelog

版本从 1.0.0 起算，之前的所有迭代记录不保留。每次改动都递增版本号：新功能 / 行为变化记 minor，修 bug 记 patch。

## 1.1.0 — 2026-11-19

- 识别留兜底：类名整批换掉（A/B 灰度、改版）时按卡片形状兜底——同类链接 ≤3、整层链接 ≤5、图片 ≤3、有封面图、文字 ≤200；直播位按链接、推荐位按 `data-mod` 前缀匹配；认不出就不动。
- 形状兜底只在首页、且确实零 `.bili-video-card` 时才启用；顶栏、页头、导航直接排除，避免把播放页的「直播」入口翻成一整栏。
- 菜单只在“类名认不出卡片、已按形状兜底”或“有卡片但一个都没认出”时多出一行 `⚠️` 提示，正常页面没有这一行。
- 新增 `?bbm=debug`：带参数时控制台打一行扫描诊断（只有计数，不含 uid / 标题 / 名单）。
- 回归测试扩到 189 条：补 A/B 双形态（老类名 DOM 与“类名全换只剩形状”的 DOM）、顶栏误伤、`?bbm=debug` 静默性，以及版本号一致性（脚本 `@version`、兜底常量、`package.json`、本文件）。
- 版本号自动化：`npm run bump -- <patch|minor|major|x.y.z> "说明"` 一次写齐脚本 `@version`、`SCRIPT_VERSION` 兜底、`package.json`、`package-lock.json` 与本文件顶部条目；`npm run version:check` 只校验。手改版本号不再必要。

## 1.0.0 — 2026-11-19

首个版本。

- 首页三类卡片各两档独立开关：广告位上下翻转、推荐位与直播位左右翻转，翻转与禁止点击分开；八档无全局一键项，`?bbm=off` 本页全关。
- 菜单行首图标即状态：广告位翻转生效 `↕️`、其余翻转生效 `↔️`、禁止点击生效 `✅`、关掉一律 `⬜`。
- 本地 UP 屏蔽名单，按 uid 判定；入口在视频播放页菜单，点中任一屏蔽理由即入名单，取消最后一项即移出。
- 固定九项屏蔽理由标签，表外标签折叠成「其他」。
- UP 行纯展示，点它不弹框：未屏蔽写「要屏蔽就点下面的理由」，已屏蔽显示第一条理由。
- 导出：明文两档只含 uid / 名字 / 时间（含标签那份加 tags），BV 与标题永不进明文；另有一档口令加密导出（AES-GCM-256 + PBKDF2-SHA256 20 万轮，≥12 位四类字符，只输一次并自解校验）。
- 导入：加密包自动识别并要求口令；形状按白名单严格校验，多一个字段整份拒绝。
- 清空名单前自动导出含标签备份，备份失败即取消。
- 扫描固定 3 秒；读名单按条数分档（≤1k 3 秒、≤5k 10 秒、≤20k 30 秒、更多 60 秒），只读到不同 uid 集合才重扫并重画菜单。
- 名单拆两个键：`bbm:blocked` 整份、`bbm:blocked:uids` 一行 uid 索引；轮询只读索引，整份在启动/菜单/导入/清空时读，索引对不上按整份重写。
- 不往控制台输出用户可见信息；控制台只剩内部异常（周期任务抛错、扫描失败、连续失败停机）。
- 仓库附 `package.json` 与 `eslint.config.mjs`，`npm run lint` 走 `@eslint/js` recommended + `no-multi-spaces` 等少量硬约束。
- 回归测试在 `tools/block.test.cjs`，`npm test` 用 jsdom 跑 166 条断言（开关、标记、屏蔽匹配、双键与索引自愈、分档轮询、导出/导入/加密）。
- 发布用 git tag 标版本（当前 `1.0.0`），jsDelivr 的 `@1.0.0` 地址可取到这份固定内容。
